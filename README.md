# Engineering Unit Converter

## What it does
The Engineering Unit Converter is a Python program designed to convert different engineering measurements quickly and accurately. It supports conversions involving length, temperature, weight, and speed. It also allows users to view their conversion history.

## How to run it
Install Python 3, then run:

python engineering_converter.py

## Sample output
ENGINEERING UNIT CONVERTER

Select an option: 1
Enter the value to convert: 25.4

---------- RESULT ----------
Original value: 25.4
Converted value: 1.0000 inches
----------------------------

## My own twist
I added a conversion history feature that allows users to view previous calculations during the program session. I also included input validation and error handling.
